02根因与模式

代码事实

TextContentOption.kt

  • inlineEdit=true（Form Inspector）：singleLine = true
  • inlineEdit=false（底栏）：摘要 maxLines=1 + 弹层字段不设 singleLine
  • 模板编辑 Sheet 字段同样允许多行
渲染事实

WatermarkCellComposer

  • TextMeasurer / MultiParagraph 测整段文本
  • 注释明确按行居中（多行水印合法）
  • 产品能力 = 引擎 OK + UI 路径被掐

抽象模式：「为了在侧栏塞下手机控件，把交互降级成 single-purpose 缩略版」，而不是「用侧栏空间升级成桌面级编辑」。 同类债会在：短字段、弹层改内联、底栏手势、About 列表、导出 sheet 上反复出现。

03交互债分类（从触发点推广）

布局 IA（ADR-0026 双栏）只解决「放哪里」。大屏还要解决「怎么用」——五类债：

A · 输入保真

编辑能力不能比手机差

多行文本、长内容滚动、校验错误常驻、撤销/重做入口。侧栏应是升级而非阉割。

B · 空间形态

弹层 → 内联 / 固定面板

手机靠 sheet 争取垂直空间；宽屏应默认内联，避免 FileDialog + Modal 叠层。About 列表可改双栏「目录|详情」。

C · 指针与键盘

Hover / 快捷键 / 焦点环

Desktop 缺：滑块微调（滚轮/方向键）、Ctrl+S 保存、Tab 焦点顺序、拖放与菜单等价入口。

D · 视口与像素

预览清晰 + 控件跟布局

已做：Fit bucket / filmstrip 随宽重居中。仍欠：缩放手柄、About 满宽浪费、导出 sheet 在宽窗仍像手机抽屉。

E · 信息密度

分区、并排、持久可见

Form 分区标题已 i18n。仍可：Style 滑块与色板同屏；导出选项与文件列表分栏；About 开源说明可读宽度。

F · 跨窗一致

同代码路径，异形态

formPath / layoutClass 分支要有契约测试：大屏路径不得偷偷砍功能（如 multiline）。

05About 页专项

AboutScreenShell 当前是手机纵向叙事：全屏光晕 → 顶栏 logo → Section 列表行 → 底部 HorizontalPager 开发者/设计师卡。没有 layoutClass / BoxWithConstraints 分支。

大屏问题
  • 内容列拉满窗口 → 行点击热区过长，视线扫描成本高
  • Dev 卡仍用 pager 滑动 —— 桌面用户期望并排两卡或 grid
  • 版本/评分/反馈与「开关项」混在同一线性流，无「设置 | 关于信息」分区密度
  • 开源/隐私二级页同样单列，未复用双栏阅读模式
建议形态（≥840）
  • 左：导航列表（信息 / 关于 / 偏好开关）
  • 右：选中项详情或外链确认
  • Dev/Designer：并排两卡，取消强制 pager
  • 内容 max-width 限制（约 720–840dp 居中）防超长行
  • Desktop：外链用系统浏览器；评分/反馈禁用或改「复制地址」

与编辑器一致的原则：Compact 保留现有 About 滚动叙事（品牌感）；Expanded+ 再分栏。 不要为了大屏拆掉橄榄色光晕品牌，只改信息架构与点击目标密度。

06设计原则（落地检查单）

01

大屏路径不得功能倒退

凡 formPath / dual-pane 分支，能力集合 ≥ 手机路径（multiline、模板、校验）。允许形态变，不允许能力删。

02

空间换持久可见，而不是换阉割控件

侧栏垂直空间应用来多行输入、分区、并排滑块+色板，而不是把字段压成 singleLine 摘要。

03

指针+键盘是一等公民（Desktop）

每个高频操作：点击、快捷键、（可选）菜单三项等价。拖放与 FileDialog 等价。

04

弹层有「大屏变体」

Bottom sheet → 居中 dialog / 侧栏内嵌 / 分栏。断点与编辑器 840 对齐。

05

可读宽度与触控热区解耦

About/开源：限制 measure；列表行在宽屏限制内容宽或用双栏，避免 1400px 宽点击条。

06

契约测试锁住路径差异

例如：inlineEdit 字段必须 !singleLine 或 minLines≥2；resize 后 filmstrip 居中；预览 bucket≥容器 Fit。

07建议落地顺序

批次 项 验收
P0 多行文本 Form 路径：去掉 inline singleLine；minLines=3；与 sheet 行为对齐；确认渲染含 \n Desktop 侧栏可输入三行；预览 cell 三行居中；电话路径无回归
P0 路径契约测试：inline 与 sheet 共享「允许换行」断言 单元/截图门禁防再阉割
P1 导出 sheet 大屏变体：≥840 居中或双栏 宽窗不再「手机抽屉」感
P1 About ≥840：内容限宽 + Dev 双卡并排；可选左右导航 1470 宽截图对比
P1 Desktop 快捷键与拖放：O/S、图标 drop 无 FileDialog 完成开图/存图主干
P1 滑块键盘/滚轮 无鼠标拖拽可调参
P2 Filmstrip 键控、焦点环、开源 TOC、draft 预览更高 bucket 体验打磨清单

与既有决策关系：ADR-0026 解决「窗格放哪」；Form Inspector DEMO 解决「控件长什么样」； 本报告补第三层——「大屏上的操作是否完整、是否桌面化」。三层都齐，Desktop 才不像「放大的手机」。
