2 · 统一根因（R0–R3）

R0 · OOM 主因

整批 Data / ByteArray 驻留

loadPickerPayloads 持有 N 份全文件 → deliverPickedPhotosBatch(List<ByteArray>) 再拷一份 → 48×~3MB HEIC ≈ 144MB+ 压缩字节峰值，再加双份拷贝与解码尖峰 → Jetsam。

R1 · 慢 / 无优先

全量屏障（batch barrier）

必须 N 张全部 loadTransferable 成功后才 stage / 出图。 焦点图必须等最后一张 FileProvider 结束。并发仅 2。

R2 · 慢 + 内存尖峰

缩略图仍「全分辨率解码再缩小」

decodeThumbnail(96) → decodeSkia(full)； HEIC 再走 UIImage 全画幅 bake + JPEG 0.92 重编码。 真机单 placeholder 1.8s decodeScale；×N filmstrip 更糟。

R3 · 争抢

filmstrip 全量 prefetch ∥ 焦点 preview

同 Dispatchers.Default，无 focus-first 调度； 可见格 produceState 冷 miss 再解；重组时出现 scope left the composition 白做功。
