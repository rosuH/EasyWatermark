# 自定义字体 UI 设计与实施计划

日期：2026-09-05。状态：Proposed，仅设计，未改产品代码。

架构依据：[ADR-0035](../../adr/0035-custom-watermark-fonts.md)。Android、iOS、Desktop 首版共用下面的布局和交互。

[打开可点击的布局示意](2026-09-05-font-panel-ui.html)：同时对照手机底部面板与宽屏居中对话框，可切换示例字体、模拟导入状态，以及关闭面板查看水印变化。

## 1. 入口放在哪里

沿用编辑器现有“样式”入口。在 `TextTypeFace` 对应的“外观”控制中，增加“字体”行，位于现有填充/描边和粗体/斜体控件之前。行内展示当前字体名称与展开箭头；默认显示“系统默认”。

大屏 inspector 在“外观”段直接展示该行；窄屏沿用已有横向 option 与展开内容，不把字体列表塞进 option slot。不新增第四个编辑器标签页，也不放到只负责文字/图片内容的 Content 面板。

字体行、标题和列表名称一律使用正常界面字体。候选字体只用于行内样例，避免缺字或装饰性字体使名称无法辨认。

## 2. 大致布局

### 手机及窄窗口

使用现有 `EwmModalBottomSheet`，从底部出现，保留上方一部分编辑器背景。按内容与窗口高度约束面板，不用固定屏幕像素撑满；长列表只在中间区域滚动。

从上到下是：

1. **标题区**：“字体”和关闭按钮。
2. **固定默认项**：“系统默认”，右侧以勾标识已提交选择，始终不随来源切换消失。
3. **来源切换**：“系统” / “已导入”。
4. **字体列表**：正常字体显示名称；下一行用该字体显示当前水印文字；右侧勾表示当前选择。
5. **底部操作区**：简短导入/错误状态；“从文件夹导入”和“完成”。两个来源下均可导入。

标题、默认项、来源切换与底部操作固定，只让列表滚动。列表高度使用剩余空间，360 dp 可作为普通窗口的列表上限参考，不能作为最小高度；小高度窗口和大字号下优先保证关闭/完成及导入仍可触达。

### 平板及桌面宽窗口

使用居中 `EwmContentDialog`，背景编辑器加现有 scrim。内部仍采用相同顺序与同一列列表，不再增加一套桌面字体管理器。

以约 560 dp 可读宽度作为初稿目标，高度不超过现有容器上限与窗口可用高度。复用项目面板色、形状、边距和动效；示意图中的颜色是某个示例主题，正式界面继续跟随应用主题。

正式切换容器必须调用 `usesLargeScreenDialog(editorLayoutClass(...))`。当前规则是 800 dp 起使用大屏对话框；600–799 dp 仍走底部面板。应按窗口而非操作系统判断，所以窄桌面窗口与窄平板窗口也走窄屏布局。

`EwmContentDialog` 现有全内容滚动不能把 footer 推出视口。实施时验证高度约束与滚动归属；必要时对容器做最小扩展以支持固定操作区，避免外层无限高度滚动嵌套内部字体列表。

## 3. 大致效果与选择交互

- 一屏可比较几个字体样例，列表名称可读，候选字体变化只体现在样例与真实编辑器水印中。
- 样例使用当前水印文字，过长时单行截断；空文本使用短的本地化样例。界面不新增独立照片渲染器或一块宣称等同导出的假预览。
- 点击候选 B 时显示加载状态，勾仍在已提交的 A 上。B 加载成功并提交后才移动勾，真实编辑器重算对应水印层。
- 面板保持打开，可以继续比较。背景预览透过 scrim 仅用于视觉反馈，不能点击操作；“完成”、关闭、返回键关闭面板后查看完整照片。
- “完成”只关闭，不额外提交，也不撤销已成功选择。尚在加载的选择由编辑器 Host 管理，关闭面板不销毁任务；若随后失败，在编辑器显示错误，重新打开仍能查看状态。
- 新选择失败时保留原字体。已提交后绘制失败遵循 ADR-0035 的等待/错误规则，不能把旧水印当作新字体效果，更不能暴露无水印的 Source/Library。
- 字体不支持某种粗体/斜体效果时，既有样式控件禁用相应选项并解释；需要归为 Normal 时，字体与样式原子提交，界面明确显示调整结果。

## 4. 导入过程怎么显示

“从文件夹导入”打开各平台原生目录选择器。Android、iOS、Desktop 的选择器外观由系统负责，不要求伪装成相同窗口。

取消系统选择器时不改变当前来源、列表或选择，也不提示失败。确认目录后显示“正在导入字体…”，可取消后台导入。成功后切换到“已导入”并显示新增字体，不自动选择其中第一项。

导入结果显示简短汇总，例如“新增 3 个，重复 1 个，失败 2 个”。这是文案示例，不是实际结果。失败详情只显示文件名和可理解的原因，不暴露原目录路径。已有字体不因部分导入失败消失。

## 5. 必须覆盖的界面状态

- **系统列表加载中**：默认项和导入入口可用，只在系统列表区域显示加载提示。
- **已导入为空**：“还没有导入字体”，提示使用底部导入按钮；默认项仍在，不另放重复的大按钮。
- **正在加载候选字体**：显示候选的进度，保留旧选择勾，其他候选可选；以较新的选择请求为准。
- **部分导入成功**：展示成功条目与汇总，允许查看失败详情。
- **无可用字体/全部失败**：保留原列表，分别说明未找到候选文件或读取失败，不混为同一种错误。
- **当前字体不可用**：显示原因，并允许点击固定“系统默认”或其他有效字体恢复；不能静默更换并继续显示旧名字。
- **Android 旧版本系统列表受限**：列表区域用简短说明解释本机仅显示基础系统字体；导入功能照常可用。

上述状态需要读屏语义，选中不能仅靠颜色表示。字体列表行至少满足现有触控尺寸要求，支持键盘导航；关闭后焦点回到字体入口。大字号、长名称、中英文、emoji 与缺字样例均要保持名称和操作按钮可读。

## 6. 具体实施任务

1. 复用共享 `TextStyleAppearanceOption` / inspector 布局加入入口，把标题与当前字体名称接到 Host。
2. 实现共享 `EditorFontSheetHost` 与字体行，落实两个容器、固定区域和中间列表滚动。
3. 接入系统/已导入列表、按可见项加载样例、选中与忙碌/错误语义；不增加搜索、收藏、删除或在线下载。
4. 将原生目录选择与导入进度通过 Host 回调接入；实现取消、空状态与部分成功结果。
5. 接入 ADR-0035 的加载后提交、能力限制和真实预览更新；完成按钮只关闭面板。
6. 新增文案进入 shared composeResources，并同步默认英文到 Weblate 路径；不手改非默认语言文件。

## 7. UI 验收

- 360 / 600 / 799 dp 为底部面板，800 dp 及以上为居中对话框，通过现有布局分类验证。
- 最大字体列表、短窗口和大字号下，默认项、关闭、导入和完成可触达；不出现双重无界滚动。
- 切换来源不丢默认项或当前选择；加载中的候选不显示成功勾；关闭不撤销已成功选择。
- 选择两种可区分字体，查看真实预览和导出图片；只检查列表高亮不算通过。
- 三端分别验证原生目录取消、空目录、损坏文件、部分成功与重启恢复。
- Android/iOS 的触控与读屏、Desktop 的键盘与缩放均有验证证据。浏览器示意页不能替代应用或设备验收。

## 8. 示意稿边界

交互示意稿展示窄屏底部面板和宽屏居中对话框，以及列表、选择和导入状态。字体是样例，导入为模拟；没有读取真实系统字体或目录，没有接入产品渲染。

本次浏览器工具拒绝访问本地 HTML URL，因此只做源文件与交互逻辑的静态检查，未完成截图级视觉验收；没有改用其他浏览器或代理服务绕过限制。实际 UI 的外观接受证据留在实施阶段。
