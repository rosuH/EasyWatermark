权限状态矩阵

Limited 是一等公民：PHPicker 不会把刚选的图加入可读集合。

状态快路径用户看到弹窗
authorized 启用 先出系统图，再淡入水印 不再弹
limited 尝试，常 miss 与今天一致（ImageIO）+ 每次进编辑器出「允许全部照片」banner 系统框已过；banner 直到 Allow All
denied 禁用 与今天一致 + 每次进编辑器 banner「去设置」 banner 直到 Allow All
restricted 禁用 与今天一致 永不弹
notDetermined 首次需要时请求一次 请求期间仍走 ImageIO 本进程一次

真机通过门（写在测之前）

Allow All · 冷切
量 derivative 上屏 水印中位不劣化。编造「快 30%」禁止上 banner。
Limited / Denied
不劣化 相对 before ≤ +10 ms / +5 ms。先修回落再谈收益。

首次需要时系统框一次；非 Allow All 则每次进编辑器出 banner（全部照片 / 去设置）。文案未测前不写百分比。

③

度量与切片

量底图上屏；Allow All 后默认开；P1 含 picker 预选；磁盘缓存另期；Release 脱敏日志可进。
