相册读权限 → 预览先快后精

目标是剪映那种「点一下就出图」。Session / 导出仍走本地文件；PhotoKit 只加速首帧。拒绝或 Limited 取不到时，行为与今天一样。

① 冷切图

首帧水印预览变快

~226ms 今 → ≤80ms 目标

Allow All 且能解析到 PHAsset：系统缩略图 + compose 先上屏，再被 ImageIO 全质量替换。Limited / 拒绝：不劣化。

② 拖参

不碰 draft，保住 Source

~7ms compose

PhotoKit 不进拖动手势。后台仍用 ImageIO 填 Source，所以拖透明度 / 间距 / 偏移时不该变差。

首帧怎么走

从上到下试；最后一级永远保留。

0
已有 Watermarked 缓存今天就有，命中直接画
1
已有 Source 占位今天就有
2
PhotoKit 快路径（新增）系统 derivative → compose → 立刻上屏；不写 Watermarked 缓存
3
ImageIO 全质量（地板）写 Source + Watermarked，覆盖快路径；拖参依赖这一步

上架前清单

硬规则（不能破）

  • Session 仍只持有文件路径 — 不用 PHAsset 当真相源
  • 导出仍全解本地文件 + 剥 EXIF — PhotoKit 不出最终成品
  • 快路径帧不进 Watermarked 缓存 — 避免永远停在软图
  • 不新增 Shared.framework 公开 API — internal + 现有通知通道
  • 身份不落盘 — 只活在内存，dispose 清空

本期不做： FFmpeg / libheifQL 当主路径磁盘缩略图同批多 scene

权限状态会怎样

状态快路径你看到的
全部允许开首帧明显快，再精修
Limited常 miss与今天一样慢；不卡死
拒绝 / 受限关与今天一样
未决定要一次弹窗期间仍走 ImageIO
