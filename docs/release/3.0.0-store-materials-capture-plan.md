### 样张准备（拍之前先备好）

准备 3–4 张**你有权公开使用**的照片，避免肖像权/版权问题：

- 一张**色彩鲜明**的风景或静物 → 用于 S2/S3，让内容取色主题好看
- 一张**模拟证件/文档**的图 → 呼应「防止身份证照片被滥用」的核心场景（自己做一张假的，别用真证件）

水印文案建议用有说服力的真实句子，例如 `仅供 XX 办理 XX 使用` / `For XX verification only`，比默认的 emoji 更能传达用途。中英文各准备一版。

### ⚠️ 设备分辨率陷阱

你手上的 OnePlus 8T（KB2000）是 **1080×2400**，比例 1:2.22，**超过 Play 的 2:1 上限，原图传不上去**。

两个解法，推荐第一个：

**方案 A — 建一个 1080×1920 的模拟器（推荐）**
原生 9:16，既满足上限也满足推荐位门槛，不用裁剪。

**方案 B — 临时改真机分辨率**

```bash
adb -s 4ddb1c5b shell wm size 1080x1920
adb -s 4ddb1c5b shell wm density 420
# ... 拍完 ...
adb -s 4ddb1c5b shell wm size reset
adb -s 4ddb1c5b shell wm density reset
```

拍完**务必 reset**，否则手机会一直卡在这个分辨率。

### 拍摄命令

# 装 3.0.0 debug 包（与线上 2.10.0 可共存，applicationId 带 .debug 后缀）

### 商店对截图来源设备的要求（政策结论，2026-08 调研）

- **App Store（审核指南 2.3.3 / 2.3 Accurate Metadata）**：截图必须展示「提交的那个构建在真机/模拟器上的实际运行画面」。允许设备边框、标题文案、背景装饰，但**框内 UI 必须是真实 iOS 应用**——用桌面版截图套 iPhone 框有被拒风险（缺 iOS 状态栏、系统控件差异都可能被审核员或自动比对识破）。iPhone 图必须来自 iPhone 尺寸（模拟器即可），iPad 图必须来自 iPad 尺寸。
- **Google Play（Deceptive Behaviour + Metadata 政策）**：截图必须准确反映真实应用体验，Google 有自动系统把商店截图与实际 App 界面比对。装饰性文案允许，但不允许榜单/价格/评价类宣传语（"#1"、"Best"、"Download now" 等）。Play 对重度装饰框比 Apple 更保守，featuring 资格要求接近裸截图。
- **结论**：本仓库的桌面端 Computer-Use 采集 + HTML 模板产物（v4 系列）用于**定稿设计、文案评审、GitHub README**；上店终图必须按第六节流程在 iOS 模拟器 / Android 模拟器分平台重拍同样的界面状态，再套用同一模板渲染。CMP 三端 UI 一致，重拍成本只在采集不在设计。

### 采集参数备忘（v5 实测）

- 样张定稿：晴空塔 `1787384879218.jpg`（第 1 张 tilt + Feature graphic 右机）、富士山停车场 `1000019783.jpeg`（hero 海报 + 功能图 + Feature graphic 左机）、富士山大景 `1000019718.jpeg`（桌面/iPad 宽幅）、AI 生成虚构证件卡 `sample-id-card.png`（办证场景）。BARK/PAWGLAM 已弃用；椰树图弃用；贴纸模式截图取消。
- 电影机位：模板 `frame.html` 的 `scene` 参数现有 `flat` / `tilt`（左倾侧机位）/ `zoom`（特写放大 + 平面微旋）/ `float`（悬浮全机 + 接触投影）/ `poster`（无手机壳，水印成品实物做主角，MD Vinyl 语言；配 `ink=dark|light`、`aw`、`rot` 参数）。商店图 2、3 定稿用 `poster`：`shot` 传的是从采集图裁出的**水印成品**（`artifact-fuji.png` / `artifact-id.png`），`amb` 传原照片（亮雾）或成品自身（暗雾）。曾试过 3D 镜像右倾（tiltr）/ 正面仰拍（low）/ zoom / float 套壳方案，均不及"实物海报"——卖成品，不卖手机。
- 桌面窗口高度被屏幕限制在 ~870pt，采集图比例约 2.0:1，小于模板框内区 ~2.12:1，会露出框底黑边——渲染时传 `dw=95` 让画面填满出血（或用比例 ≥2.12 的采集图）。
