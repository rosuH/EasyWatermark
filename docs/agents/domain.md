# Domain Docs

This is a single-context repo.

Before non-trivial engineering work, read:

- `AGENTS.md` for repo guidance before changing code.
- `docs/CONTEXT.md` for EasyWatermark domain vocabulary and invariants.
- Relevant ADRs under `docs/adr/`.

Use the glossary's vocabulary in issue titles, plans, tests, and refactor proposals. If a proposal contradicts an ADR, surface the conflict explicitly instead of silently overriding it.
